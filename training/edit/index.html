연수 페이지 편집

이 화면에서 바꾼 내용은 GitHub 저장소에 바로 저장되고, 약 1분 안에 shy.ai.kr/training에 반영됩니다. 저장하려면 본인 GitHub 계정의 접근 토큰이 필요합니다. 토큰은 이 브라우저에만 저장되며 GitHub 외의 다른 곳으로 전송되지 않습니다.

토큰 만드는 방법 (한 번만 하면 됩니다)
  1. github.com/settings/personal-access-tokens/new 를 엽니다. (Fine-grained token)
  2. Token name: shy-training-edit 처럼 알아볼 수 있는 이름을 적습니다.
  3. Expiration: 가능한 가장 긴 기간을 고릅니다. 만료되면 같은 방법으로 다시 만들면 됩니다.
  4. Repository access: Only select repositories → sehunYang.github.io 하나만 선택합니다.
  5. Permissions → Repository permissions → Contents: Read and write 로 바꿉니다. 다른 권한은 그대로 둡니다.
  6. Generate token을 누르고, 표시된 토큰(github_pat_…)을 복사해 아래에 붙여넣습니다. 토큰은 그 화면을 벗어나면 다시 볼 수 없으니 바로 붙여넣으세요.
